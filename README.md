# Sign-Language
 Deep Learning multi-class image classification model that recognizes  (A–Z, space, delete, nothing). The system uses Convolutional Neural Networks and Transfer Learning with EfficientNetB0 . The final model is also deployed in a real-time Gradio interface, allowing users to upload images or use a webcam to convert hand signs into text.
